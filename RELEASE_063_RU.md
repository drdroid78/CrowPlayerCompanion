# CrowPlayer Companion 0.6.3 — USB-связь с CrowPanel

## Изменения

- Заменён BLE-транспорт на Android USB host / CDC ACM, который использует прошивка CrowPanel.
- При подключении панель определяется по CDC-интерфейсам; Android показывает системный запрос разрешения.
- Компаньон передаёт состояние трека, прогресс, время, часовой пояс и известное состояние лайка по USB CDC JSON-lines v1.
- Команды play/pause, предыдущий/следующий трек и like принимаются от панели. Like проверяет название, исполнителя и ожидаемое состояние перед выполнением; результат возвращается на панель.
- Настройки яркости, LED, темы и энкодера выполняются на панели; убраны недействующие BLE-переключатели и ползунки.
- Обложки по USB пока не передаются.

## Первое подключение

1. Соедини панель с USB-C/OTG планшета кабелем, поддерживающим передачу данных.
2. Открой CrowPlayer 0.6.3 и подтверди системный запрос на доступ к USB-устройству.
3. В карточке подключения проверь статус «Связь с CrowPanel установлена по USB».
4. Разреши приложению доступ к уведомлениям, запусти Яндекс Музыку и проверь название/исполнителя на панели.

Планшет должен работать в режиме USB host (OTG), CrowPanel — в режиме USB device. При отсутствии устройства проверь OTG-адаптер и кабель передачи данных.

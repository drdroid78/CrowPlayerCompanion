# Официальная база Elecrow для CrowPanel 1.28″

Проверено 12 ноября 2026 года.

Репозиторий: https://github.com/Elecrow-RD/CrowPanel-1.28inch-HMI-ESP32-Rotary-Display-240-240-IPS-Round-Touch-Knob-Screen

Зафиксированный коммит master: `d7a766ca14780ee2e4865d3a865483234e4aeea9`.
Последний коммит датирован 21 октября 2026 года и добавляет 3D-модель. Наличие исправленного энкодера подтверждено чтением кода, а не названием последнего коммита.

## Совместимая исходная база

Свежий `example/Arduino/Examples/README.md` указывает:

- Arduino-ESP32 Core **3.3.8**.
- LVGL **9.1.0** (также подтверждено `libraries/lvgl/library.properties`).
- PSRAM включена для примеров LVGL.

Версии поставляемых библиотек:

- LovyanGFX **1.2.26**.
- Adafruit NeoPixel **1.15.1**.
- Драйвер CST816D поставляется непосредственно рядом с примерами.

Главный `readme.md` всё ещё упоминает LVGL 8.3.11. Это противоречит свежим примерам и комплекту библиотек. Новую прошивку следует собирать с согласованным набором зависимостей; старые вызовы LVGL 8 нельзя смешивать с новыми вызовами LVGL 9.

## Энкодер

Основной пример: `example/Arduino/RotaryScreen_1_28/RotaryScreen_1_28.ino` (дублируется в `factory_soucecode/RotaryScreen_1_28`).

- A = GPIO45, B = GPIO42, кнопка = GPIO41.
- Прерывания на изменении обоих каналов A/B.
- Таблица из 16 переходов состояний; полный шаг формируется из четырёх переходов.
- ISR накапливает счётчик шагов; обработка интерфейса выполняется в основном контексте, а не в прерывании.
- Для счётчика вращения предусмотрена критическая секция.
- Кнопка: временная фильтрация 20 мс, окно двойного нажатия 300 мс.

Это подходящая основа для замены простого опроса GPIO в прежней прошивке CrowPlayer. Сам по себе этот пример не доказывает полное отсутствие дребезга на нашей плате: потребуется проверить направление, число отсчётов на фиксированный шаг, быстрые повороты и нажатия. При адаптации отдельно проверить атомарное чтение/сброс счётчиков кнопки и поведение при недопустимых переходах A/B.

`example/Arduino/Examples/Lesson03-Rotate` содержит более короткий вариант того же табличного декодирования, но с опросом из loop(). `example/Simple example/Encoder_code` использует более простой подсчёт фронтов; это не основной образец для новой обработки вращения.

## Подтверждённые выводы из примеров

| Функция | GPIO |
|---|---|
| Экран GC9A01: SCLK / MOSI / DC / CS / RST | 10 / 11 / 3 / 9 / 14 |
| Подсветка дисплея | 46 |
| Сенсор CST816D: SDA / SCL / RST / INT | 6 / 7 / 13 / 5 |
| Энкодер A / B / кнопка | 45 / 42 / 41 |
| Пять адресных LED, GRB 800 кГц | 48 |
| Native USB D− / D+ | 19 / 20 |
| UART в учебном примере: TX / RX | 43 / 44 |
| Управление питанием в основном примере | GPIO1 = HIGH, GPIO2 = HIGH |
| POWER_LIGHT в основном примере | GPIO40 = LOW |

GPIO4 в Lesson03 управляет отдельным учебным LED. Для пяти адресных светодиодов используется GPIO48, что подтверждено `example/Simple example/RGB_CODE/RGB_CODE.ino`.

Назначение GPIO43/44 для UART подтверждено примером внешнего Wi-Fi-модуля. Разъём, уровни и подключение именно к HAM необходимо сверить со схемой платы и спецификацией усилителя, а не переносить учебную схему подключения автоматически.

## Сенсор и USB

- CST816D предоставляет координаты касания и коды жестов вверх/вниз/влево/вправо. Он подходит как исходная база сенсорного ввода; распознавание наших действий и конфликтов жестов будет частью приложения панели.
- Lesson06-USB2.0 — пример **USB HID-мыши**, не канал обмена данными с Android-компаньоном.
- Для HID-мыши пример требует USB-OTG/TinyUSB (`ARDUINO_USB_MODE=0`) и явно отличает его от Hardware CDC/JTAG. Режим и интерфейс нашего USB-канала надо настроить под выбранный протокол отдельно.
- Заводские `.bin` и инструкция прошивки присутствуют у производителя. Они относятся к демонстрационной заводской прошивке, а не к CrowPlayer.

## Статус интеграции

Распиновка, табличная обработка энкодера и безопасное чтение CST816D перенесены в новую прошивку. Библиотеки устанавливаются по зафиксированным версиям при сборке, целиком в репозиторий не копируются. Интерфейс использует LVGL 9.1.0. Реализация и ограничения описаны в `PANEL_FIRMWARE_RU.md`; аппаратные испытания ещё не выполнялись.

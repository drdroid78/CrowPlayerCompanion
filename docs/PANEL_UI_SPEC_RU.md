# CrowPanel Škoda Edition — интерфейс и управление

Обновлено по обсуждению 12 ноября 2026 года. Этот документ фиксирует требования к панели. Реализация и текущие ограничения новой USB/UART-прошивки описаны в `PANEL_FIRMWARE_RU.md`.

## Требования пользователя

- CrowPanel 1.28″ ESP32-S3R8, круглый сенсорный экран 240×240, энкодер с кнопкой и пять адресных светодиодов по кругу.
- Панель получает медиаданные от Android-компаньона. Связь с планшетом исключительно по USB.
- Воспроизведение, переключение треков и лайки относятся к планшету.
- Громкость и выбор источника относятся к HAM 4.8 DSP; соединение с усилителем по UART.
- Регулировка громкости доступна и энкодером, и жестом на сенсорном экране.
- Экраны переключаются жестами.
- Дежурный экран показывает время и использует выбранную цветовую тему.
- Яркость автоматически меняется по времени суток, день/ночь.
- Все пять адресных светодиодов используют цвет темы; их можно задействовать для индикации действий.
- Установка прошивки по USB, обновление по Wi-Fi. Wi-Fi не используется для связи с планшетом.

## Предлагаемая логика для согласования

### Навигация и действия

- Горизонтальный свайп меняет экран: часы → музыка → звук → источники → настройки.
- Вертикальный свайп на основных экранах регулирует громкость усилителя: вверх громче, вниз тише.
- Поворот энкодера регулирует громкость HAM. На экране звука отдельная выбранная шкала сабвуфера может использовать энкодер, если регулировка подтверждена протоколом усилителя.
- В настройках вертикальный жест используется для выбора/прокрутки параметров, чтобы настройка не меняла громкость случайно. Энкодер остаётся доступен для громкости, кроме явно открытого режима редактирования.
- Касание сердечка запрашивает изменение избранного через компаньон. Видимое подтверждение зависит от ответа компаньона, а не от самого касания.
- Касания предыдущего/следующего трека и воспроизведения отправляют соответствующие команды компаньону.
- Дежурный экран появляется после периода без действий; действие пользователя пробуждает рабочий экран. Предлагаемое значение — 30 секунд, с возможностью отключить автоматический переход.
- Точные назначения одиночного/двойного нажатия и удержания кнопки энкодера ещё согласовать.

### День / ночь

Предлагаемые начальные значения, а не утверждённые фиксированные ограничения:

| Параметр | День | Ночь |
|---|---:|---:|
| Начало периода | 07:00 | 22:00 |
| Экран | 80% | 18% |
| Адресные светодиоды | 35% | 6% |

- Начало дня/ночи и оба уровня яркости настраиваются отдельно для дисплея и светодиодов.
- Переход плавный, ориентировочно две секунды, без краткого выхода на максимальную яркость.
- Часы синхронизируются с компаньоном по USB с учётом местного времени. Потеря USB не должна сразу сбрасывать последнее синхронизированное время.
- До первой синхронизации времени: `--:--`, пониженная яркость и понятный статус подключения.
- Значения времени и временных меток в прошивке должны исключать найденное переполнение 32-битного epochMs.
- Сохранение темы, расписания, уровней яркости и времени перехода на дежурный экран в энергонезависимой памяти панели.

### Пять светодиодов

- В покое — спокойный постоянный свет в цвет темы с отдельной дневной/ночной яркостью.
- Изменение громкости — один яркий световой акцент перемещается по кругу в направлении поворота энкодера, остальные светодиоды приглушены; после остановки подсветка плавно возвращается к фоновому уровню. Одинаково для HAM и HID; эффект показывает направление действия, а не измеренное значение громкости.
- Переключение экрана — короткое последовательное выделение светодиодов по направлению жеста.
- Подтверждённый лайк или смена источника — один мягкий импульс цвета темы.
- Нет подтверждения / потеря связи — отличимый короткий двойной импульс; цвет темы сохраняется.
- В режиме mute — приглушённый свет. Индикация не должна мешать чтению экрана и не должна блокировать обработку команд.
- Предлагаемые эффекты и длительности пока являются частью макета и требуют согласования и проверки на реальных светодиодах.

## Внешний вид

Основа — семь присланных снимков Screenshot_20261108_050220 … 050358:

- Чёрный фон, круговая шкала, компактные контрастные надписи, сменный цвет акцента.
- Темы: Tornado Red, Lapiz Blue, Reflex Silver, Indium Grey, Urano Grey, Atlantic Blue, Pure White, Škoda Green.
- Музыка: обложка/заглушка, кольцо прогресса, время трека, название/исполнитель, сердечко.
- Звук: громкость HAM, mute; сабвуфер только при подтверждённой поддержке протокола.
- Источники HAM: динамический список из SOURCE_CONFIG; активный источник выделен. В присланном захвате: OPT, LOW, HIGH, BT, USB. Это входы усилителя, не варианты соединения панели с планшетом.
- Настройки: тема, расписание дня/ночи, яркость экрана/подсветки, дежурный режим и прочие подтверждённые параметры.

## Реализация

В прошивку перенесены пять экранов LVGL, жесты, энкодер, кнопка, темы/NVS, часы, расписание яркости, пять LED и UART HAM с подтверждением фактических значений. USB CDC реализован на стороне панели; компаньон 0.6.2 ещё требует USB-транспорта. Снимки экранов генерируются из того же кода UI с демонстрационными данными. Передача обложек и DSP-пресеты пока не реализованы.

Схема, сборка, протокол USB и аппаратные ограничения — в `PANEL_FIRMWARE_RU.md`. Читаемость, ориентацию сенсора, направление энкодера и обмен с HAM предстоит проверить на физическом устройстве.

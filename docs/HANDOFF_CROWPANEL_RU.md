## Последнее обсуждение: скорость графики панели
Пользователь попросил оценить возможность ускорения и улучшенного драйвера. Выполнен анализ кода; оптимизация НЕ внесена. Затем пользователь попросил чекпоинт и продолжить позже.
Проверенные настройки:
- GC9A01 через LovyanGFX 1.2.26, SPI2, freq_write=80000000, dma_channel=SPI_DMA_CH_AUTO.
- LVGL 9.1.0, RGB565, PARTIAL, один буфер uint16_t[240*40] (19200 байт).
- flush_cb вызывает lcd.pushImage(), затем lv_display_flush_ready().
- panel_ui.cpp::render() каждый раз вызывает lv_obj_clean(root) и создаёт элементы заново.
- В loop() renderInterval: 180 мс для volumeOverlay, иначе 60 мс. Также принудительный render каждые 1000 мс.
- USB state и отчёты HAM помечают UI dirty; во многих случаях перестраивается весь экран.
- Полный кадр 240*240*2=115200 байт, теоретический минимум передачи при 80 МГц — 11.52 мс без накладных расходов. Это расчёт, НЕ измерение FPS устройства.

План следующего этапа:
1. Добавить измерения времени построения UI, flush/переданных пикселей и задержки реакции на энкодер.
2. Сохранить объекты LVGL между обновлениями, обновлять только изменившиеся элементы; исходный дизайн сохранить.
3. Исследовать более частое обновление оверлея громкости.
4. Затем рассмотреть два внутренних DMA-совместимых буфера и корректную асинхронную передачу с уведомлением LVGL только после освобождения буфера.
Не утверждать, что DMA сейчас отключён: он разрешён в конфигурации; реальное поведение pushImage надо сверить с закреплённой версией библиотеки.
Не переписывать GC9A01 с нуля без измерений. Не обещать конкретный выигрыш FPS без проверки на панели.
Документация: https://lvgl.io/docs/open/9.1/porting/display

## Устройство и архитектура

- Панель Elecrow CrowPanel 1.28, ESP32-S3R8, круглый сенсор 240 × 240, энкодер с кнопкой и пять адресных светодиодов.
- Android-планшет подключается к панели только по USB. Панель управляет воспроизведением и лайком через компаньон; громкостью планшета — также через USB HID.
- Усилитель HAM управляется по UART 115200 8N1. Сигнал инвертирован, уровень усилителя 1,8 В: необходимо согласование уровней. Не подключать линии напрямую без проверки. Доступные источники определяются сообщением усилителя.
- Возможность CAN пока лишь исследовалась: GPIO38/39 рассматриваются как кандидаты, но подключение и уровни на конкретной плате не проверены.

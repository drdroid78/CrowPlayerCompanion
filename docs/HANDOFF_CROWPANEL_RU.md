## С чего начать на другом компьютере

Клонировать репозиторий и переключиться на ветку `feature/crowplayer-0.6.0`. Не считать `main` актуальной рабочей версией. Открыть этот файл и проверить новые коммиты и состояние рабочего дерева. При работе с графикой сначала показывать Павлу макет и получать его согласие; не заменять утверждённый дизайн своим вариантом.

Проверенная точка до этой заметки: `216d1ae3f4e236d4ae1fde276d205134e5f9602b`. Код проекта и история этого локального чата — разные вещи: чат автоматически не переносится вместе с репозиторием.

## Устройство и архитектура

- Панель Elecrow CrowPanel 1.28, ESP32-S3R8, круглый сенсор 240 × 240, энкодер с кнопкой и пять адресных светодиодов.
- Android-планшет подключается к панели только по USB. Панель управляет воспроизведением и лайком через компаньон; громкостью планшета — также через USB HID.
- Усилитель HAM управляется по UART 115200 8N1. Сигнал инвертирован, уровень усилителя 1,8 В: необходимо согласование уровней. Не подключать линии напрямую без проверки. Доступные источники определяются сообщением усилителя.
- Возможность CAN пока лишь исследовалась: GPIO38/39 рассматриваются как кандидаты, но подключение и уровни на конкретной плате не проверены.

Павел сообщил, что в 0.6.8 обложки не показываются. На фото диагностика избранного: приложение Яндекс Музыка, Media ID `447`, аккаунт показан подключённым, точное сопоставление трека не удалось. Это не доказывает, на каком этапе теряется обложка.

В 0.6.9 получение обложки исправлено: числовой Media ID сверяется с названием и исполнителем, затем возможен поиск по метаданным; недоступный URI медиасессии не должен прерывать резервный поиск. Исправлено распознавание посторонних ссылок как ID Яндекса. Есть автоматический тест случая неверного числового ID. На реальном планшете версия 0.6.9 ещё не проверена: выяснить, видна ли обложка в приложении, затем на панели; по результату исследовать получение, USB-передачу и отображение. Не утверждать, что обложки работают, до проверки.

# CrowPlayer Companion — тестовая версия 0.1.0

Это диагностический Android-проект для проверки, может ли HarmonyOS 3.0.0 на Huawei MatePad SE
передавать приложению медиаданные активной сессии Яндекс Музыки.

## Что делает эта версия

- Запрашивает системный доступ к уведомлениям (Notification Listener).
- Получает список активных MediaSession через MediaSessionManager.
- Показывает название, исполнителя, альбом, состояние воспроизведения и обложку, если они
  предоставляются медиасессией.
- Обновляет экран примерно раз в секунду.

**Это ещё не готовая связка с CrowPanel.** Bluetooth LE-протокол и команды пульта будут добавлены
после того, как проверим, что HarmonyOS действительно отдаёт медиаданные Яндекс Музыки.

## Как получить APK без Android Studio на планшете

Сборка выполняется в GitHub Actions в облаке.

1. На планшете открой GitHub в браузере и войди в аккаунт (если аккаунта нет — создай).
2. Создай новый пустой репозиторий, например `CrowPlayerCompanion`.
3. Распакуй архив проекта и загрузи **все файлы и папки** в корень репозитория через веб-интерфейс GitHub.
   Важно: папка `.github/workflows` тоже должна быть загружена.
4. Открой вкладку **Actions** репозитория. Если GitHub попросит разрешить workflows — разреши.
5. Выбери **Build CrowPlayer Companion APK** и нажми **Run workflow**.
6. После завершения открой выполненный запуск и скачай артефакт
   `CrowPlayer-Companion-debug`.
7. Распакуй скачанный ZIP — внутри будет `app-debug.apk`. Нажми на APK и установи его.
   Если HarmonyOS спросит разрешение на установку приложений из браузера/файлов — разреши для этого источника.

## Проверка на планшете

1. Открой CrowPlayer Companion.
2. Нажми **Открыть доступ к уведомлениям**.
3. В настройках включи доступ для CrowPlayer Companion.
4. Запусти Яндекс Музыку из AppGallery и начни воспроизведение.
5. Вернись в CrowPlayer Companion. Посмотри, появились ли название, исполнитель и состояние.
6. Если обложка не появилась, это не обязательно означает сбой: конкретная медиасессия может не публиковать bitmap.

## Если данные не появились

- Убедись, что музыка реально воспроизводится, а не просто открыто приложение.
- Проверь, что системный доступ к уведомлениям включён.
- Открой экран приложения снова.
- Пришли скриншот экрана CrowPlayer Companion и страницы разрешения.

HarmonyOS может ограничивать совместимость некоторых Android API. Поэтому это именно проверочная сборка, а не обещание полной совместимости до испытания на устройстве.

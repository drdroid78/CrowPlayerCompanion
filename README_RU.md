# CrowPlayer ŠKODA Edition

Проект BLE HID медиапульта для Elecrow CrowPanel 1.28-inch HMI ESP32-S3 и Android Companion для Huawei MatePad SE / HarmonyOS.

Автор: **DrDroid78**.

См. `RELEASE_050_RU.md` для списка функций, настройки OTA и ограничений проверки.

Текущая разработка Android Companion: **0.6.1**, ветка `feature/crowplayer-0.6.0`. Изменения управления избранным и порядок проверки на планшете описаны в `RELEASE_061_RU.md`. Прошивка остаётся на предыдущем этапе.

Android-проект находится в `android/`. Прошивка Arduino IDE — `firmware/CrowPlayer/CrowPlayer.ino`.

# CrowPlayer — комплект для CrowPanel 1.28 HMI + Huawei MatePad SE

**Автор проекта: DrDroid78**  
**Версия исходников: 0.3.1 (интеграционный прототип с обновлённым интерфейсом приложения).** В комплекте находятся прошивка ESP32-S3 и Android-приложение-компаньон. Проект подготовлен под CrowPanel 1.28-inch HMI ESP32-S3R8 (GC9A01 240×240, CST816D, энкодер) и Huawei MatePad SE с HarmonyOS 3.0.0 и Яндекс Музыкой из AppGallery.

> Важно: приложение уже проверено на планшете на получение названия трека и исполнителя. Полный комплект с CrowPanel пока не проверялся на реальной плате — она ещё в доставке. Поэтому это готовая для сборки тестовая версия, но не заявление о завершённом аппаратном тестировании.

## Что уже реализовано

- Два рабочих экрана прошивки: Bluetooth-сопряжение и экран плеера.
- При включении — заставка с выбранной круглой неоново-изумрудной эмблемой Š на весь дисплей 240×240.
- Пять встроенных NeoPixel постоянно светятся приглушённым изумрудно-зелёным оттенком; цвет включён постоянно, без мигания и анимации.
- BLE HID медиаклавиши: громкость ±, Play/Pause, предыдущий и следующий трек.
- Отдельный BLE GATT-сервис для передачи метаданных из приложения на ESP32.
- Android-компаньон читает активную MediaSession через NotificationListenerService и отправляет на CrowPanel название, исполнителя и состояние воспроизведения.
- Android-приложение использует круглую иконку с эмблемой Š, показывает авторство DrDroid78 и оформлено в тёмной теме с изумрудными акцентами Škoda: брендовая шапка, карточка плеера, крупная обложка, название, исполнитель/альбом, индикатор воспроизведения и отдельные карточки подключения/настроек.
- На планшете приложение показывает метаданные и обложку, если Яндекс Музыка предоставляет её через MediaSession.
- GitHub Actions собирает APK автоматически.

## Что пока ограничено

- Обновлённый дизайн приложения — это визуальное оформление, а не отдельный музыкальный плеер: кнопки настройки и подключения выполняют реальные действия, но управление воспроизведением пока остаётся через BLE HID-пульт.

- Обложка пока отображается только в приложении на планшете; передача картинки на круглый дисплей — следующий этап после проверки связи.
- Полоса прогресса на дисплее пока декоративная: Android-проект ещё не передаёт позицию/длительность трека.
- Прошивка не может узнать фактическую системную громкость через BLE HID. Процент на экране — оценка изменения громкости энкодером, а не чтение громкости MatePad.
- Сенсор CST816D пока не задействован. Управление сделано энкодером.
- Совместимость одновременного BLE HID-соединения и GATT-соединения с HarmonyOS нужно подтвердить на конкретной плате.

## Часть 1. Собрать приложение-компаньон APK

Текущая версия приложения — **0.3.1**. Автор проекта: **DrDroid78**. После установки проверь в сведениях о приложении, что отображается CrowPlayer Škoda.

1. Создай или открой GitHub-репозиторий `CrowPlayerCompanion`.
2. Загрузи **содержимое всего архива** в корень репозитория. Важно загрузить скрытую папку `.github` вместе с `workflows/build-companion.yml`.
3. Открой вкладку **Actions**. Разреши GitHub Actions, если он попросит.
4. Выбери workflow **Build CrowPlayer Companion APK** и нажми **Run workflow**. При загрузке файлов в ветку `main` сборка также стартует автоматически.
5. Дождись зелёного `Success`, открой запуск и нажми число рядом с `Artifacts`.
6. Скачай `CrowPlayer-Companion-debug.zip`, распакуй. Внутри будет `app-debug.apk`.
7. Установи APK на MatePad. Если HarmonyOS запросит разрешение на установку из этого источника, разреши его.

### Настройка приложения на MatePad

1. Запусти CrowPlayer Companion.
2. Нажми **Открыть доступ к уведомлениям** и разреши доступ для CrowPlayer.
3. Запусти Яндекс Музыку и включи трек. Убедись, что название и исполнитель отображаются — эта проверка уже прошла на планшете пользователя.
4. Когда CrowPanel будет прошит и сопряжён, вернись в приложение и нажми **Подключить CrowPanel**. Разреши доступ к Bluetooth, если система спросит.
5. Оставь приложение открытым на время первого теста.

## Часть 2. Прошить CrowPanel

### Arduino IDE и библиотеки

Рекомендуемая среда:

- Arduino IDE 2.3.x
- ESP32 Arduino Core 3.3.7 или новее в ветке 3.x
- NimBLE-Arduino 2.3.8 или новее (проект проверялся по API ветки 2.x)
- HijelHID_BLEKeyboard (Arduino Library Manager: `HijelHID`)
- LovyanGFX
- ArduinoJson 7.x
- Adafruit NeoPixel 1.15.x

Установи библиотеки через **Sketch → Include Library → Manage Libraries**. Для `HijelHID` ищи `HijelHID`; для остальных — точные имена выше. Также установи `Adafruit NeoPixel` от Adafruit.

### Параметры платы

1. Открой `firmware/CrowPlayer/CrowPlayer.ino` в Arduino IDE.
2. Выбери плату **ESP32S3 Dev Module**.
3. Для первого теста: USB CDC On Boot = Enabled; Flash Size = 16MB; PSRAM = OPI PSRAM (если параметр доступен); Upload Speed = 460800 или ниже при ошибках.
4. Подключи CrowPanel USB-кабелем к компьютеру и выбери его COM-порт.
5. Нажми Upload. Если загрузка не начинается, удерживай BOOT, кратко нажми RESET, отпусти BOOT и повтори Upload.

### Сопряжение и запуск

1. После включения на 2,2 секунды появится круглая эмблема Š, затем экран покажет **Bluetooth / Pair with CrowPlayer**. Изумрудная подсветка пяти NeoPixel остаётся включённой постоянно.
2. На MatePad открой настройки Bluetooth и выполни сопряжение с устройством **CrowPlayer** (это BLE HID-пульт).
3. Открой CrowPlayer Companion, включи доступ к уведомлениям, запусти Яндекс Музыку.
4. Нажми в приложении **Подключить CrowPanel**. Приложение ищет BLE-устройство с именем `CrowPlayer` и подключается к пользовательскому GATT-сервису.
5. После HID-сопряжения экран переключится на плеер. При получении данных от приложения на экране появятся название и исполнитель.

## Управление энкодером

- Поворот по часовой стрелке — громкость вверх.
- Поворот против часовой стрелки — громкость вниз.
- Короткое нажатие — Play/Pause.
- Двойное нажатие — предыдущий трек.
- Удержание около 0,7 секунды — следующий трек.

## BLE-протокол

- Service UUID: `7d2ea28a-f7bd-485a-bd9d-92ad6ecfe93e`
- Characteristic UUID: `7d2ea28b-f7bd-485a-bd9d-92ad6ecfe93e`
- Запись UTF-8 JSON: `{"title":"...","artist":"...","state":"playing"}`
- `state` принимает `playing` или `paused`.

## Если что-то не работает

- Если приложение не находит плату: проверь, что прошивка запущена, HID-сопряжение выполнено, Bluetooth включён, а разрешения Bluetooth выданы приложению.
- Если CrowPanel не появляется в настройках Bluetooth: удали старую запись `CrowPlayer` на планшете, перезагрузи плату и попробуй снова.
- Если приложение видит медиаданные, но экран не обновляется: пришли скриншот приложения и фото дисплея; отдельно проверим GATT-соединение.
- Если Arduino IDE сообщает об ошибке компиляции: пришли полный текст ошибки и версии ESP32 Core / NimBLE-Arduino / HijelHID.

## Заставка Škoda на круглом дисплее (обновление)

При старте CrowPanel прошивка выводит круглую эмблему CrowPlayer Škoda Edition на весь экран GC9A01 240×240 примерно на 2,2 секунды, затем открывает экран Bluetooth-сопряжения. Изображение хранится в `firmware/CrowPlayer/skoda_splash.h` в формате RGB565 и включается непосредственно в прошивку; отдельная SD-карта или загрузка файла не нужны. Пять NeoPixel остаются постоянно подсвеченными приглушённым изумрудно-зелёным цветом.


## CrowPlayer ŠKODA Edition 0.4.0

В версии 0.4.0 расширен JSON-протокол BLE GATT: `positionMs`, `durationMs`, `nightMode`, `screenBrightness`, `ledBrightness` передаются вместе с названием, исполнителем и состоянием воспроизведения. Прошивка отображает оценку прогресса и временные метки, регулирует яркость подсветки дисплея и NeoPixel. Настройки доступны в приложении Companion. Автор проекта: DrDroid78.

**Ограничения этой сборки:** передача обложек на круглый дисплей ещё не реализована в BLE-протоколе; обложка отображается в приложении, но на CrowPanel пока остаётся графический placeholder. Позиция трека зависит от MediaSession HarmonyOS и может обновляться с задержкой. Проверка на физической плате обязательна.
